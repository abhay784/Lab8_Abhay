# Lab8-Starter
Abhay Korlapati
Gracefull degradation is when you develop and design your product so that even when certain features don't work or it isn't working in ideal conditions it performs at a reduced capacity rather than not at all. In this lab in can do offline caching and can work without internet showing how even in non ideal situations it works. Service workers are what allow for offline caching with event handling and appearing dormant till needed.
